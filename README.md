# HRMS Frontend

React (Vite) frontend for HR & Payroll Management System.

## Tech Stack
- React (Vite)
- react-router-dom
- axios
- react-bootstrap + bootstrap
- react-hook-form + yup
- recharts
- Context API (state management)

## Setup

\`\`\`bash
npm install
cp .env.example .env
npm run dev
\`\`\`

Backend must be running at the URL configured in `.env` (default: `http://localhost:8081/api/v1`).

## Project Structure
See `src/` — organized by `api/`, `context/`, `layouts/`, `components/`, `pages/`, `hooks/`, `utils/`.
